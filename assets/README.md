# Artwork

`partlet.svg` is the original project logo. `partlet.png` is its
transparent 256 x 256 raster version, rendered from the same SVG.

A mint project tile leaves a stack of directories and becomes a
standalone repository card, on a rounded ink background.

The SVG uses self-contained vector geometry with accessible title and
description text. It has no fonts, scripts or external resources. The
artwork is covered by the repository's MIT license.
