# Worker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Cloudflare Worker in `worker/` that serves one source's published projects from R2, read-only: the site index, project pages, directory listings, file pages, raw files with safe content types, the latest archives, and the Git dumb-HTTP files, so that `git clone https://<site>/<name>` and `git pull` work. The Worker's gates (lint and format, typecheck, tests on the Workers runtime) run in `scripts/check.sh`, the hooks and CI.

**Architecture:** Three TypeScript modules. `route.ts` is a pure function from a URL path to a route (or null), and is the only place request input is validated. `policy.ts` holds the pure header policy: content types, caching, CSP, the raw-file classifier and the `Range` parser. `index.ts` is the fetch handler: it resolves a route to an R2 key (through the project's `current` file where the URL is stable), reads it with `get` or `head`, and builds the response. Tests run in workerd through vitest and `@cloudflare/vitest-plugin`, against a simulated R2 bucket seeded with the publisher's layout.

**Tech Stack:** Node 24.22.0, npm 11.19, TypeScript 7.0.2, wrangler 4.151.1, vitest 5.0.5, `@cloudflare/vitest-plugin` 1.4.4, Biome 2.5.15. Compatibility date `2026-10-01`.

**Spec:** `docs/specs/2026-10-15-partlet-design.md` (Worker, R2 layout, Dumb-HTTP Git layout, Testing). **Layout as built:** `src/partlet/publish.py`, `gitstatic.py`, `site/render.py`, `site/urls.py` at `688469a`, plus the `publish-orphan-sweep` change (removes `cleanup.json`; `current` gains a `previous` record; `write_pointers` briefly lists old and new packs together). The Worker reads only `build` and `tip` from `current` and serves whatever pack list is stored; Review Focus 4 explains why the transient pack list is safe to cache for 60 seconds.

## Review Focus

1. **Raw files never execute on the site origin.** `raw/` serves images (png, jpg, jpeg, gif, webp, by extension) with their types; other text as `text/plain; charset=utf-8`; HTML, SVG, XML and related markup, and anything binary, as `application/octet-stream` with `Content-Disposition: attachment`. Every non-page response also carries `X-Content-Type-Options: nosniff` and `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; sandbox`, so a wrong type still yields no script and an opaque origin. Check `evil.html`, `evil.svg`, `evil.js` and an HTML-bodied `.png`. Tests in Tasks 3 and 4.
2. **Path traversal and percent-encoding.** Each path segment is decoded once with `decodeURIComponent`; a malformed escape, invalid UTF-8, an empty segment, `.`, `..`, an encoded `/` (`%2F`) or NUL is a 404 without a bucket read. The WHATWG URL parser already folds `..` and `%2e%2e`, but the Worker does not rely on that. Names with spaces, `#`, `?`, `%` and non-ASCII characters must round-trip to the publisher's key; the Worker applies no Unicode normalization. `!'()*~` decode the same whether escaped (Python's `quote`) or not (browsers, `encodeURIComponent`). A directory named `index.html` maps to its own page key, distinct from its parent's. Invalid UTF-8 such as `%FE` is a 404 until `site-git-path-identity` settles how such names are published. Tests in Tasks 2 and 4.
3. **No key outside the project, and no internal keys.** Keys are built only from: `SOURCE` (checked against the name rule on every request, a bad value is a 500), a validated project name, a fixed section, decoded file segments, and `build`/`tip` values from `current` that must match their hex formats (otherwise 500). Git paths come from a fixed list. `current` and any other key in a project prefix have no URL. Only `build` and `tip` are read from `current`; the test fixture's `current` carries the publisher's `previous` field and the "follows current" test uses a `current` with only `build` and `tip`, so both shapes are covered. Tests in Tasks 2 and 4.
4. **`current` indirection and caching.** Pages, raw files and archives live under immutable keys (a build prefix, a tip SHA) but are served at stable URLs resolved through `current`, so they get `public, max-age=60` with the object's ETag, not `immutable`. Only packs and pack indexes are `immutable`. Errors are `no-store`. A 304 comes only from `If-None-Match`; other conditional headers are not passed to R2, because R2 answers any failed precondition with a bodiless object. Check that this departure from the spec's caching section (it lists build-prefix files and archives by SHA as immutable, but no URL exposes them) is acceptable, and that a 60-second stale window after a publish is. The Worker accepts only 16-hex build IDs, so a change to `build_id()` in `publish.py` needs a Worker change. **Transient pack lists:** when a publish consolidates packs, `write_pointers` first lists the dropped and the new packs together, moves `info/refs`, then writes the final list. Every pack either list names exists in the bucket: the new pack is uploaded first, and the dropped packs are recorded in `current["previous"].packs` and kept until the sweep at the end of the next publish. So a client holding any `objects/info/packs` up to 60 seconds old, transient or final, finds its packs unless two publishes complete inside those 60 seconds; then a pack may be a 404, git fails that fetch, and a retry reads the new list. That 404 is `no-store`, so it is not cached; caching a pack as immutable stays correct because a pack's name is its content hash and a deleted pack is never rewritten under the same name. Tests in Task 4.
5. **Git dumb-HTTP files under GET and HEAD.** `/<name>/HEAD`, `info/refs` (also with `?service=git-upload-pack`, answered with the plain file as `text/plain`, so git falls back to the dumb protocol) and `objects/info/packs` revalidate; packs are immutable and honour a single `bytes=N-[M]` range (git resumes interrupted pack downloads with one and appends the body to its partial file). The HTTP `HEAD` method returns the same status and headers as GET, with `Content-Length`, for every route. The Worker passes a null body for HEAD, but the runtime drops a HEAD response's body anyway (checked: the HEAD tests still pass with that code removed), so the tests can only check status, headers and length. `?service=git-receive-pack` is a 403; methods other than GET and HEAD are 405. Tests in Task 4; clone and pull through `wrangler dev` in Task 6.
6. **404 behaviour.** Unknown projects, unknown paths, non-routes and keys missing from a build all return the same small HTML 404 page with `no-store`. Nothing falls through to a listing or to another project's files. A damaged `current` is a 500, not a 404, so it shows up. Tests in Task 4.
7. **Toolchain trust.** Exact pins, a committed lockfile, `npm ci` in setup and CI, install scripts allowed for two named packages only, and `scripts/worker-test.sh` unsets Cloudflare credential variables before running vitest. Task 1.

Also guarded, with tests in the owning tasks: the `.git` alias (`/foo.git/info/refs`, and `/foo.git.git` is a 404), trailing slashes (accepted on the project page and listings only), archives requested under another project's name (`/foo/archive/bar.zip` is a 404), and a text file larger than the 8000-byte sniff window.

## What the R2 publishing plan (plan 3) depends on from this one

- The key layout and URL contract under Global Constraints, and the `current` format (`build` 16 hex, `tip` 40 hex). The Worker tests seed that layout by hand in `worker/test/site.ts`; plan 3's end-to-end test is what proves the publisher and the Worker agree.
- The Worker ignores stored content types, so the R2 store does not need to set them for correctness (it may, for direct bucket access).
- `wrangler dev --local --var SOURCE:<source> --persist-to <dir>` serves a local R2 bucket named by `bucket_name` in `wrangler.toml` (`replace-me` until the user fills it in). Task 6 shows the working sequence. Loading objects with `wrangler r2 object put --local` costs about a second per object (one process each), so plan 3's end-to-end test should load the local bucket another way, for example through Miniflare's API in one process.
- `scripts/setup.sh` installs the Worker toolchain and CI's `check` job installs Node from `worker/.node-version` (Task 5), so an end-to-end CI job can reuse both.
- Clone URLs are `{base_url}/{name}` (`site/render.py`), served by the Worker without the `.git` suffix.

## Out of scope

- Edge caching with the Workers Cache API. Responses carry `Cache-Control` for browsers and git clients, but every request reaches R2 (Worker responses on a custom domain are not cached at the edge on their own).
- `Range` on anything but packs and pack indexes.
- A `robots.txt`, favicon, or a 404 page rendered by the publisher.
- The R2 write token, monorepo secrets and the publish workflow (plan 3).

- [ ] **Step 4: Write the Worker stub and generate the types**

`worker/src/index.ts`:

```ts
// Partlet Worker: serve one source's published projects from R2.
//
// Read-only by construction: the bucket binding is only read (get and head),
// there are no write paths, and the Worker holds no other credentials. All
// rendering happens in the publisher; this file maps URLs to stored objects
// and chooses the response headers.

export default {
  async fetch(request): Promise<Response> {
    if (request.method !== "GET" && request.method !== "HEAD") {
      return new Response("Method not allowed\n", { status: 405, headers: { Allow: "GET, HEAD" } });
    }
    return new Response("Not found\n", { status: 404 });
  },
} satisfies ExportedHandler<Env>;
```

Generate the types only after `src/index.ts` exists: wrangler adds `GlobalProps.mainModule` from the entry point, which is what types `exports.default` in the tests.

```ts
// Map a request path to what it names in the store. Pure: no I/O.
//
// Every route this returns is safe to turn into a store key: project names
// match the manifest's name rule, file paths are decoded segment by segment
// and never contain "", ".", "..", "/" or NUL, and Git paths come from a
// fixed list. Anything else is null, which the Worker answers with a 404
// without reading the bucket.

export const NAME_RE = /^[a-z0-9][a-z0-9._-]*$/;
const PACK_RE = /^pack-(?:[0-9a-f]{40}|[0-9a-f]{64})\.(?:pack|idx)$/;

// Keys under a project's live site build, as the publisher writes them
// (src/partlet/site/render.py). The Worker builds them here and nowhere else,
// so a change to the publisher's layout is one edit in this file.
export const SITE_KEYS = {
  project: "index.html",
  tree: (dir: string) => `tree/${dir}/index.html`,
  blob: (path: string) => `blob/${path}`,
  raw: (path: string) => `raw/${path}`,
};

export const ARCHIVE_FORMATS = ["tar.gz", "zip"] as const;
export type ArchiveFormat = (typeof ARCHIVE_FORMATS)[number];

export type Route =
  | { kind: "index" }
  | { kind: "asset"; asset: "style.css" | "index.json" }
  // `key` is relative to the live site build (SITE_KEYS); `path` is the
  // file's path in the project.
  | { kind: "page"; project: string; key: string }
  | { kind: "raw"; project: string; path: string; key: string }
  | { kind: "archive"; project: string; format: ArchiveFormat }
  // `path` is the key under the project's git/ prefix.
  | { kind: "git"; project: string; path: string; immutable: boolean };

function decodeSegments(pathname: string): string[] | null {
  const segments: string[] = [];
  for (const raw of pathname.split("/").slice(1)) {
    let segment: string;
    try {
      segment = decodeURIComponent(raw);
    } catch {
      return null; // malformed escape or invalid UTF-8
    }
    if (segment === "." || segment === ".." || segment.includes("/") || segment.includes("\0")) {
      return null;
    }
    segments.push(segment);
  }
  return segments;
}

function filePath(segments: string[]): string | null {
  if (segments.length === 0 || segments.includes("")) return null;
  return segments.join("/");
}

function projectName(segment: string): string | null {
  const name = segment.endsWith(".git") ? segment.slice(0, -4) : segment;
  return NAME_RE.test(name) && !name.endsWith(".git") ? name : null;
}

function gitRoute(project: string, rest: string[]): Route | null {
  const path = rest.join("/");
  if (path === "HEAD" || path === "info/refs" || path === "objects/info/packs") {
    return { kind: "git", project, path, immutable: false };
  }
  if (
    rest.length === 3 &&
    rest[0] === "objects" &&
    rest[1] === "pack" &&
    PACK_RE.test(rest[2] ?? "")
  ) {
    return { kind: "git", project, path, immutable: true };
  }
  // Loose objects, alternates and anything else: the publisher writes only
  // packs, so these are always 404.
  return null;
}

export function parseRoute(pathname: string): Route | null {
  if (pathname === "/") return { kind: "index" };
  const segments = decodeSegments(pathname);
  if (segments === null) return null;

  const [first, ...rest] = segments;
  if (first === "_partlet") {
    if (rest.length === 1 && (rest[0] === "style.css" || rest[0] === "index.json")) {
      return { kind: "asset", asset: rest[0] };
    }
    return null;
  }
  const project = projectName(first ?? "");
  if (project === null) return null;

  // A single trailing slash is accepted on the project page and directory
  // listings only; a file path never ends in "/".
  const [section, ...tail] = rest;
  if (rest.length === 0 || (rest.length === 1 && section === "")) {
    return { kind: "page", project, key: SITE_KEYS.project };
  }
  if (section === "tree") {
    const dirs = tail.at(-1) === "" ? tail.slice(0, -1) : tail;
    if (dirs.length === 0) return { kind: "page", project, key: SITE_KEYS.project };
    const dir = filePath(dirs);
    return dir === null ? null : { kind: "page", project, key: SITE_KEYS.tree(dir) };
  }
  if (section === "blob" || section === "raw") {
    const path = filePath(tail);
    if (path === null) return null;
    return section === "blob"
      ? { kind: "page", project, key: SITE_KEYS.blob(path) }
      : { kind: "raw", project, path, key: SITE_KEYS.raw(path) };
  }
  if (section === "archive") {
    if (tail.length !== 1) return null;
    const format = ARCHIVE_FORMATS.find((f) => tail[0] === `${project}.${f}`);
    return format ? { kind: "archive", project, format } : null;
  }
  return gitRoute(project, rest);
}
```

```ts
// Response headers: content types, caching and the security headers every
// response carries. Pure: no I/O.

// Packs are content-addressed and never rewritten.
export const CACHE_IMMUTABLE = "public, max-age=31536000, immutable";
// Everything at a stable URL, including pages, raw files and archives whose
// stored key is resolved through the project's `current` file.
export const CACHE_REVALIDATE = "public, max-age=60";
export const CACHE_NONE = "no-store";

// Rendered pages: the stylesheet and images only, never scripts, frames,
// forms or a <base> override. README images may be hosted elsewhere (https).
export const PAGE_CSP =
  "default-src 'none'; style-src 'self'; img-src 'self' https:; " +
  "base-uri 'none'; form-action 'none'; frame-ancestors 'none'";
// Everything else (raw files, Git files, archives, JSON, errors): if a
// browser renders it as a document at all, it gets an opaque origin and no
// script, even when the content type below is wrong.
export const FILE_CSP = "default-src 'none'; style-src 'unsafe-inline'; sandbox";

export const HTML = "text/html; charset=utf-8";
export const TEXT = "text/plain; charset=utf-8";
export const OCTET = "application/octet-stream";
export const CSS = "text/css; charset=utf-8";
export const JSON_TYPE = "application/json";

// The number of leading bytes a raw file is classified from; the same
// window git and the publisher's is_binary() use for the NUL check.
export const SNIFF_BYTES = 8000;

const IMAGE_TYPES: Record<string, string> = {
  png: "image/png",
  jpg: "image/jpeg",
  jpeg: "image/jpeg",
  gif: "image/gif",
  webp: "image/webp",
};

// Markup a browser would render as an active document if it ignored the
// content type: always a download, even though it is text.
const MARKUP_EXTENSIONS = new Set([
  "htm",
  "html",
  "shtml",
  "xht",
  "xhtml",
  "mht",
  "mhtml",
  "svg",
  "svgz",
  "xml",
  "xsl",
  "xslt",
]);

export const GIT_TYPES = {
  pack: "application/x-git-packed-objects",
  idx: "application/x-git-packed-objects-toc",
} as const;

export const ARCHIVE_TYPES = { "tar.gz": "application/gzip", zip: "application/zip" } as const;

function extension(name: string): string {
  const dot = name.lastIndexOf(".");
  return dot <= 0 ? "" : name.slice(dot + 1).toLowerCase();
}

// Text means: no NUL byte and valid UTF-8 within the first SNIFF_BYTES.
// `truncated` says the file continues past `prefix`, so a multi-byte
// character cut off at the end is not an error.
export function looksLikeText(prefix: Uint8Array, truncated: boolean): boolean {
  if (prefix.includes(0)) return false;
  try {
    new TextDecoder("utf-8", { fatal: true, ignoreBOM: true }).decode(prefix, {
      stream: truncated,
    });
    return true;
  } catch {
    return false;
  }
}

export function attachment(filename: string): string {
  const encoded = encodeURIComponent(filename).replace(
    /['()*]/g,
    (c) => `%${c.charCodeAt(0).toString(16).toUpperCase()}`,
  );
  return `attachment; filename*=UTF-8''${encoded}`;
}

export interface RawType {
  contentType: string;
  disposition: string | null;
}

// Content type for a file under raw/: images by extension, other text as
// text/plain, and everything else (markup and binary) as a download.
export function rawType(path: string, prefix: Uint8Array, truncated: boolean): RawType {
  const name = path.slice(path.lastIndexOf("/") + 1);
  const ext = extension(name);
  const image = IMAGE_TYPES[ext];
  if (image) return { contentType: image, disposition: null };
  if (!MARKUP_EXTENSIONS.has(ext) && looksLikeText(prefix, truncated)) {
    return { contentType: TEXT, disposition: null };
  }
  return { contentType: OCTET, disposition: attachment(name) };
}

export function baseHeaders(contentType: string, csp: string, cacheControl: string): Headers {
  return new Headers({
    "Content-Type": contentType,
    "Content-Security-Policy": csp,
    "Cache-Control": cacheControl,
    "X-Content-Type-Options": "nosniff",
  });
}

// One `bytes=<first>-[<last>]` range, or null to ignore the header and send
// the whole object, which RFC 9110 allows. Git asks for a range when it
// resumes an interrupted pack download.
export function parseRange(
  header: string,
  size: number,
): { offset: number; length: number } | "unsatisfiable" | null {
  const match = /^bytes=(\d+)-(\d*)$/.exec(header);
  if (!match) return null;
  const first = Number(match[1]);
  if (match[2] && Number(match[2]) < first) return null;
  if (first >= size) return "unsatisfiable";
  const last = Math.min(match[2] ? Number(match[2]) : size - 1, size - 1);
  return { offset: first, length: last - first + 1 };
}
```

```ts
// Partlet Worker: serve one source's published projects from R2.
//
// Read-only by construction: the bucket binding is only read (get and head),
// there are no write paths, and the Worker holds no other credentials. All
// rendering happens in the publisher; this file maps URLs to stored objects
// and chooses the response headers.

import {
  ARCHIVE_TYPES,
  attachment,
  baseHeaders,
  CACHE_IMMUTABLE,
  CACHE_NONE,
  CACHE_REVALIDATE,
  CSS,
  FILE_CSP,
  GIT_TYPES,
  HTML,
  JSON_TYPE,
  PAGE_CSP,
  parseRange,
  rawType,
  SNIFF_BYTES,
  TEXT,
} from "./policy";
import { NAME_RE, parseRoute, type Route } from "./route";

const BUILD_RE = /^[0-9a-f]{16}$/;
const TIP_RE = /^(?:[0-9a-f]{40}|[0-9a-f]{64})$/;

class Unreadable extends Error {}

interface Current {
  build: string;
  tip: string;
}

const NOT_FOUND_HTML = `<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Not found</title>
<link rel="stylesheet" href="/_partlet/style.css">
</head>
<body>
<header class="top"><a href="/">Partlet</a></header>
<main>
<h1>Not found</h1>
<p>There is no project or file at this address.</p>
</main>
</body>
</html>
`;

function notFound(request: Request): Response {
  const headers = baseHeaders(HTML, PAGE_CSP, CACHE_NONE);
  return new Response(request.method === "HEAD" ? null : NOT_FOUND_HTML, { status: 404, headers });
}

function plain(status: number, message: string, extra: Record<string, string> = {}): Response {
  const headers = baseHeaders(TEXT, FILE_CSP, CACHE_NONE);
  for (const [name, value] of Object.entries(extra)) headers.set(name, value);
  return new Response(`${message}\n`, { status, headers });
}

// The project's `current` file names its live site build and tip. Both are
// checked before they go into a key, so a damaged file cannot point outside
// the project's prefix.
async function readCurrent(env: Env, project: string): Promise<Current | null> {
  const object = await env.BUCKET.get(`${env.SOURCE}/p/${project}/current`);
  if (object === null) return null;
  let parsed: unknown;
  try {
    parsed = JSON.parse(await object.text());
  } catch {
    throw new Unreadable(`p/${project}/current is not JSON`);
  }
  const { build, tip } = (parsed ?? {}) as Record<string, unknown>;
  if (typeof build !== "string" || !BUILD_RE.test(build)) {
    throw new Unreadable(`p/${project}/current has no valid build`);
  }
  if (typeof tip !== "string" || !TIP_RE.test(tip)) {
    throw new Unreadable(`p/${project}/current has no valid tip`);
  }
  return { build, tip };
}

// Only If-None-Match is passed to R2. Any other conditional header would make
// R2 return an object without a body, which would be answered with a wrong
// 304; ignoring those headers is allowed and sends the full response.
function ifNoneMatch(request: Request): Headers {
  const headers = new Headers();
  const value = request.headers.get("If-None-Match");
  if (value !== null) headers.set("If-None-Match", value);
  return headers;
}

function reply(request: Request, body: ReadableStream | null, status: number, headers: Headers) {
  return new Response(request.method === "HEAD" ? null : body, { status, headers });
}

// Serve one stored object, honouring If-None-Match.
async function serveObject(
  request: Request,
  env: Env,
  key: string,
  headers: Headers,
): Promise<Response> {
  const object = await env.BUCKET.get(key, { onlyIf: ifNoneMatch(request) });
  if (object === null) return notFound(request);
  headers.set("ETag", object.httpEtag);
  if (!("body" in object)) return new Response(null, { status: 304, headers });
  headers.set("Content-Length", String(object.size));
  return reply(request, object.body, 200, headers);
}

// Packs are immutable, so a range never needs If-Range or If-None-Match.
async function servePack(
  request: Request,
  env: Env,
  key: string,
  headers: Headers,
): Promise<Response> {
  headers.set("Accept-Ranges", "bytes");
  const header = request.headers.get("Range");
  if (header === null) return serveObject(request, env, key, headers);
  const head = await env.BUCKET.head(key);
  if (head === null) return notFound(request);
  const range = parseRange(header, head.size);
  if (range === null) return serveObject(request, env, key, headers);
  if (range === "unsatisfiable") {
    return plain(416, "Range not satisfiable", { "Content-Range": `bytes */${head.size}` });
  }
  const object = await env.BUCKET.get(key, { range });
  if (object === null || !("body" in object)) return notFound(request);
  const last = range.offset + range.length - 1;
  headers.set("ETag", object.httpEtag);
  headers.set("Content-Range", `bytes ${range.offset}-${last}/${object.size}`);
  headers.set("Content-Length", String(range.length));
  return reply(request, object.body, 206, headers);
}

// Raw files: the content type depends on the first bytes, so read those with
// a ranged get before serving the object.
async function serveRaw(request: Request, env: Env, key: string, path: string): Promise<Response> {
  const head = await env.BUCKET.head(key);
  if (head === null) return notFound(request);
  let prefix = new Uint8Array(0);
  if (head.size > 0) {
    const length = Math.min(head.size, SNIFF_BYTES);
    const probe = await env.BUCKET.get(key, { range: { offset: 0, length } });
    if (probe === null) return notFound(request);
    prefix = new Uint8Array(await probe.arrayBuffer());
  }
  const type = rawType(path, prefix, head.size > SNIFF_BYTES);
  const headers = baseHeaders(type.contentType, FILE_CSP, CACHE_REVALIDATE);
  if (type.disposition !== null) headers.set("Content-Disposition", type.disposition);
  return serveObject(request, env, key, headers);
}

async function serveProjectFile(
  request: Request,
  env: Env,
  route: Extract<Route, { kind: "page" | "raw" | "archive" }>,
): Promise<Response> {
  const current = await readCurrent(env, route.project);
  if (current === null) return notFound(request);
  const prefix = `${env.SOURCE}/p/${route.project}`;
  const site = `${prefix}/site/${current.build}`;
  switch (route.kind) {
    case "page":
      return serveObject(
        request,
        env,
        `${site}/${route.key}`,
        baseHeaders(HTML, PAGE_CSP, CACHE_REVALIDATE),
      );
    case "raw":
      return serveRaw(request, env, `${site}/${route.key}`, route.path);
    case "archive": {
      const headers = baseHeaders(ARCHIVE_TYPES[route.format], FILE_CSP, CACHE_REVALIDATE);
      headers.set("Content-Disposition", attachment(`${route.project}.${route.format}`));
      return serveObject(request, env, `${prefix}/archive/${current.tip}.${route.format}`, headers);
    }
  }
}

async function handle(request: Request, env: Env, route: Route): Promise<Response> {
  const source = env.SOURCE;
  switch (route.kind) {
    case "index":
      return serveObject(
        request,
        env,
        `${source}/index.html`,
        baseHeaders(HTML, PAGE_CSP, CACHE_REVALIDATE),
      );
    case "asset":
      return route.asset === "style.css"
        ? serveObject(
            request,
            env,
            `${source}/static/style.css`,
            baseHeaders(CSS, FILE_CSP, CACHE_REVALIDATE),
          )
        : serveObject(
            request,
            env,
            `${source}/index.json`,
            baseHeaders(JSON_TYPE, FILE_CSP, CACHE_REVALIDATE),
          );
    case "git": {
      const key = `${source}/p/${route.project}/git/${route.path}`;
      if (route.path === "info/refs") {
        const service = new URL(request.url).searchParams.get("service");
        if (service === "git-receive-pack") return plain(403, "This repository is read-only.");
      }
      if (route.immutable) {
        const type = route.path.endsWith(".pack") ? GIT_TYPES.pack : GIT_TYPES.idx;
        return servePack(request, env, key, baseHeaders(type, FILE_CSP, CACHE_IMMUTABLE));
      }
      return serveObject(request, env, key, baseHeaders(TEXT, FILE_CSP, CACHE_REVALIDATE));
    }
    default:
      return serveProjectFile(request, env, route);
  }
}

export default {
  async fetch(request, env): Promise<Response> {
    if (request.method !== "GET" && request.method !== "HEAD") {
      return plain(405, "Method not allowed", { Allow: "GET, HEAD" });
    }
    if (!NAME_RE.test(env.SOURCE)) {
      console.error("SOURCE is not set to a valid source name");
      return plain(500, "This site is not configured.");
    }
    const route = parseRoute(new URL(request.url).pathname);
    if (route === null) return notFound(request);
    try {
      return await handle(request, env, route);
    } catch (e) {
      if (!(e instanceof Unreadable)) throw e;
      console.error(e.message);
      return plain(500, "This project's published state is unreadable.");
    }
  },
} satisfies ExportedHandler<Env>;
```

A raw request costs three bucket operations (`head`, a ranged `get` of at most 8000 bytes, the full `get`); every other route costs one, plus one for `current` where the URL goes through it, plus one `head` for a ranged pack request.

````markdown
# Partlet Worker

Serves one source's published projects from an R2 bucket: the site pages,
raw files, archives, and the Git dumb-HTTP files that `git clone` and
`git pull` read. It only reads the bucket and holds no other credentials.
The URL scheme is in the [design spec][spec] and the reasons for its
caching and content-type choices are in [DECISIONS][decisions].

[spec]: ../docs/specs/2026-10-15-partlet-design.md
[decisions]: ../docs/DECISIONS.md

## Development

`bash scripts/setup.sh` installs the toolchain: the Node version in
`.node-version` and the packages locked in `package-lock.json`. The gates
are `scripts/worker-lint.sh`, `scripts/worker-typecheck.sh` and
`scripts/worker-test.sh`; `scripts/check.sh` runs all three.

`worker-configuration.d.ts` is generated. After changing a binding or
variable name in `wrangler.toml`, or the Worker's exports, regenerate it
with `npm run types` and commit the result. Changing only the values does
not require this.

## Previewing a local build

This needs no Cloudflare account and costs nothing. Build a site with
`partlet build`, load it into wrangler's local R2, and serve it:

```bash
export WRANGLER_SEND_METRICS=false
partlet build --repo <monorepo> --out /tmp/partlet-out
cd worker
(cd /tmp/partlet-out && find . -type f | sed 's#^\./##') | while IFS= read -r key; do
  npx wrangler r2 object put "replace-me/$key" --file "/tmp/partlet-out/$key" \
    --local --persist-to /tmp/partlet-r2
done
npx wrangler dev --local --var SOURCE:<source> --persist-to /tmp/partlet-r2
```

`<source>` is `[site] source` from the monorepo's `partlet.toml`, and
`replace-me` is `bucket_name` in `wrangler.toml`; use your value once it is
filled in. Keep `--local` on every `r2 object put`: without it wrangler
writes to the real bucket of the logged-in account. Loading takes about a
second per file.

## Deploying

The repository owner runs these steps. R2 and Workers are billable
Cloudflare services; nothing in this repository runs them automatically.

1. Have a Cloudflare account with R2 enabled, and the site's domain as a
   zone in that account.
2. From this directory, log in: `npx wrangler login`.
3. Create the bucket: `npx wrangler r2 bucket create <bucket>`. Leave
   public access to the bucket off; the Worker is its only reader.
4. In `wrangler.toml`, replace the three `replace-me` values: `SOURCE`
   (the `[site] source` value), `bucket_name` (the bucket from step 3) and
   the `routes` pattern (the hostname the site is served on).
5. Check the bundle and bindings without uploading anything:
   `npx wrangler deploy --dry-run`.
6. Deploy: `npx wrangler deploy`. With `custom_domain = true` this also
   creates the DNS record and certificate for the hostname.
7. Check: `curl -sI https://<hostname>/` answers 404 until the first
   publish, with `X-Content-Type-Options: nosniff`. After a publish,
   `git clone https://<hostname>/<name>` works.

The R2 write token and the monorepo secrets that publishing needs are set
up with `partlet publish`, not here.
````

```markdown
## 2026-10-17

| Decision | Reason and trade-off |
| --- | --- |
| Pages, raw files and archives are served with `max-age=60` and an ETag, although they are stored under a build prefix or by tip SHA; only packs and pack indexes are `immutable`. | Every public URL for them is stable (`/<name>/blob/<path>`, `/<name>/archive/<name>.zip`) and resolves through `current`, so a long cache would pin old content after a publish. No URL exposes a build ID or archive SHA, so the spec's original rule had nothing to apply to. Cost: browsers revalidate after a minute. |
| The Worker picks a raw file's content type from its extension and its first 8000 bytes; HTML, SVG, XML and related markup always download. | The publisher stores raw files without a content type and the local store drops types, so there is no stored type to trust. Text is served as `text/plain`, which with `nosniff` and a sandbox CSP never executes. Cost: three bucket operations per raw request, and a file whose invalid UTF-8 starts after byte 8000 is served as text while its file page calls it binary. |
| Worker-owned URLs live under `/_partlet/` (`style.css`, `index.json`). | Project names cannot start with `_`, so nothing there can shadow a project. `index.json` is a valid project name, so `/index.json` could. |
| Git paths other than `HEAD`, `info/refs`, `objects/info/packs` and `objects/pack/pack-*.{pack,idx}` are a 404 without a bucket read. | The publisher writes only packs, so loose objects and alternates never exist, and a fixed list keeps every other key in a project's `git/` prefix unreachable. A publisher that writes loose objects needs a Worker change. |
| Only `If-None-Match` is passed to R2's `onlyIf`. | R2 answers any failed precondition with a bodiless object, so passing `If-Match` or `If-Unmodified-Since` through would produce a wrong 304. Ignoring those headers is allowed. |
| `objects/info/packs` revalidates after 60 seconds like `info/refs`, though the publisher may briefly list superseded packs alongside new ones. | Every pack a list names, transient or final, is kept until the sweep at the end of the following publish, so a list up to 60 seconds old only names missing packs if two publishes finish within that minute; git then fails the fetch and a retry succeeds. Packs themselves stay `immutable`: names are content hashes and are never reused. |
| `Range` is honoured for packs and pack indexes only. | git resumes an interrupted pack download with a `Range` request and appends the body to its partial file, so a full 200 there corrupts the pack. Other files are re-downloaded whole. |
| Lint and format the Worker with Biome, not ESLint and Prettier. | One pinned dev dependency and one config file. Cost: Biome's rule set instead of ESLint's plugins. |
| Worker tests use `@cloudflare/vitest-plugin`, the renamed `@cloudflare/vitest-pool-workers`. | The old package is deprecated on npm and gets no updates. Storage is isolated per test file, so tests seed once per file and use their own project names where they change state. |
| Keep `wrangler.toml`, though Cloudflare recommends `wrangler.jsonc` for new projects. | TOML matches the rest of the repository and the spec, and nothing here needs a JSON-only Wrangler feature. Revisit if one is needed. |
| `worker-configuration.d.ts` is generated by `wrangler types --strict-vars=false`, committed, and checked with `--check` by the typecheck gate. | Cloudflare recommends committing it for CI. Without strict vars `SOURCE` is typed `string`, so filling in deploy values does not make the file stale. |
```
